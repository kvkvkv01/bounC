# bounC

A simple game where balls bounce and flip tiles. Developed in C as a study project exploring the Win32 API.

## Controls

- `N` - Add two new balls for each side. Things get really chaotic really fast.
- `R` - Reset

## Build

### Using Make (MinGW/GCC)

```bash
make
```

### Using Visual Studio

```bash
build.bat
```
